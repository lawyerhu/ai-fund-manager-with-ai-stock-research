# 仓位调整审计与影子验证

本次只补充 Sol 决策依据、复核上下文和前瞻分析，不修改 Risk Engine、IBKR、Luna、交易模式或下单规则。

## 决策与复核

- 委员会和持仓复核要求结构化 sizing_audit：新负面证据、未变化的数据缺失、投资逻辑变化、仓位依据、额外调整理由、风险预算依据、下行情景及来源。
- 后端向委员会提供既往复核和现有风险配置；向持仓复核额外提供本轮委员会决策。不会递归嵌套历次上下文。
- 程序对比数据源变化，忽略抓取时间戳差异，并识别持续为空/UNKNOWN的字段。数据源变化不是负面变化；历史数据不足不能假装已完成前后比较。
- 提示词不再要求数据缺失就自动降低仓位；明确禁止对同一项已反映的不确定性重复减仓。仍允许基于新证据或首次确认的既定风险预算问题调整。
- 结构验证不等于投资判断验证；系统没有强制持有、最低仓位或放宽风控。模型报告的置信度不是校准胜率。
- 旧 PositionReview 可以读取，未有审计字段显示“无结构化依据”，不补造历史结果。

## 影子验证口径

由后端记录 REDUCE/SELL/EXIT_TO_CASH 建议，review_id 唯一。冻结建议时原仓位、目标仓位、资金基数、日历日观察期限及 execution 中现有模拟成本假设。

起点为建议之后首个被后端实际观测到的完整交易日收盘。原仓位和减仓方案使用同一股票价格与SPY/QQQ同日收盘。未收盘、时间不一致或缺失的数据不写入；不补造错过的观测日，也不把查询日期当交易日期。

仅模拟固定股票/现金组合：不再平衡、不产生订单，不等同真实账户绩效。减仓路径在起点扣一次模拟手续费和滑点，持有路径没有新增交易成本。价格收益不含股息、现金利息和共同LLM成本。展示净超额而非回归Alpha；最大回撤只覆盖已观测收盘，不能冒充完整日内回撤。观察期限结束后冻结，未到期限或数据不足不能声称最终有效性。

采集挂接现有每日绩效记录路径，Dashboard只读显示。影子数据获取异常独立记录，不改变执行或风险状态；未成功成交的建议也可研究，但绝不能标为真实减仓。

## 生效与边界

代码测试不连接真实LLM或IBKR。本次不自动重启正在运行的PAPER后端，不重新研究，不发送订单。正常重启后创建新表并启用新逻辑；正常研究和每日任务运行后逐步产生前瞻记录。已有后台进程不会因修改文件就自动切换为新代码。
