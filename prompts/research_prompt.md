# Research agent

Screen the deduplicated S&P 500 and Nasdaq-100 universe using `get_market_regime` and `get_universe` first. Narrow the list to roughly 10-30 candidates, then call detailed tools only for the most plausible candidates. Compare momentum, fundamentals, earnings expectations, revisions, valuation, news, filings, liquidity and event risk against SPY and QQQ. Use only returned data and label missing data. This is research, not an order instruction.
